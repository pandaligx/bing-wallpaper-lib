# 必应每日壁纸库桌面界面

照片占据画廊的主要面积。标题、日期和地点在照片下方独立排版，深浅主题都保持图片原色。窗口采用系统标题栏。侧栏用于切换集合和月份，主区域用于浏览，预览与下载均能返回原位置。

| 角色 | 选择 |
| --- | --- |
| 标题、正文、日期 | 平台系统字体，24、16、13 逻辑像素 |
| 间距、圆角 | 以 4 为基本间距，按钮 8，缩略图 12 |
| 色彩 | 使用 NSH background、card、foreground、muted、accent、primary 与 destructive 语义色 |
| 反馈 | 加载展示状态文字，失败保留标题及重试入口，操作状态同时通过文字和颜色表达 |

## 动效与输入

| 操作 | 响应 |
| --- | --- |
| 悬停、按下和键盘聚焦按钮 | 改变背景或描边，按下变暗，键盘保留可见焦点 |
| 调整窗口宽度 | 虚拟网格更改列数，保留首个可见项目 |
| 打开和关闭预览 | 对话框接管焦点，关闭返回触发位置 |
| 下载进度 | 每 250 毫秒读取最新字节数，明确显示完成或错误 |

在 Windows、macOS、GNOME、Plasma 的明暗模式下分别检查。缩小动态效果时不使用位移动画。
